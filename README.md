# Dossiê

Painel para organizar a application para universidades dos Estados Unidos: pilares com progresso, objetivos do mês, tarefas, calendário de prazos, college list personalizável, documentos, mentoria e anotações.

- Funciona direto no navegador, sem servidor. Os dados ficam salvos no próprio navegador (exporte um backup em Ajustes).
- Instalável no celular e no computador como app (PWA).
- A conexão com uma pasta do computador funciona no Chrome e no Edge para desktop.

## Rodar localmente

```bash
python -m http.server 5190
```

Depois abra http://localhost:5190.
